# LeadHunter AI

LeadHunter AI is a desktop application built with Python and CustomTkinter that helps freelancers find businesses for outreach.

## Features

- Search businesses
- Store leads in SQLite
- Export to Excel
- Modern desktop interface
- AI-ready architecture

## Technologies

- Python
- CustomTkinter
- SQLite
- OpenPyXL
- Git
- GitHub
